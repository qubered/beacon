Navigation — simple to walk, fast to fly

One rail, three groups. Observe · Build · Platform — ten destinations, every one a single hop. No nesting, no hamburger, no second sidebar.

⌘K is the power spine. Any device, monitor, flow, incident or action in two keystrokes. Results carry context (state, owner, path) and the shortcut that would have done it — the palette teaches the fast way while doing the slow way.

Keys everywhere. j/k move lists, ↵ opens, g-chords jump (g d devices, g i incidents, g w wall), ? shows the sheet. The mouse is never required; it is also never punished.

The shell never changes. Top bar (mark · context · ⌘K · clock), rail, work area, status bar — on every page. Immersive surfaces collapse the rail to icons; nothing disappears.

Selection drives the right rail. Pick a run, an incident, an agent, a node — detail appears in the same place with the same anatomy every time.

Every state is a URL. A monitor at a time range, a run capture, a draft diff — all addressable, all shareable, straight from Grafana back into the byte that explains the dip.

The rules that make it Beacon

Rules, not boxes. Hairlines, whitespace and the label voice structure a screen. A box means an object: a node, a popover, a hex viewport.

Color is state. Chrome is achromatic. When something is saturated, it is telling you the truth about a device, a series, or a selection — never decorating.

Quiet until something matters. Normal is dim. Only abnormal states earn brightness, and only unacknowledged-down earns motion (a slow pulse, honoring reduced-motion).

If it’s data, it’s mono. Values, addresses, timestamps, hex, durations — IBM Plex Mono, tabular. Prose and labels — Archivo.

A refusal carries a suggestion. Every blocked action names its reason and, where one exists, the node or setting that fixes it.

Segments, not gradients. Time and level render as discrete segments — readable across a room, honest about buckets.
